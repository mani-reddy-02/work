About MediQuee Healthcare Solutions

MediQuee is an integrated digital health infrastructure company delivering seamless connectivity between patients, licensed clinicians, accredited hospitals, diagnostic pathology laboratories, and home healthcare nursing providers across India.

Meta WhatsApp Business Cloud API Integration

MediQuee utilizes Meta's WhatsApp Business Cloud API to provide patient-centric, real-time healthcare notifications:

  • Transactional Notifications Only: Used solely for One-Time Passwords (OTPs), live doctor queue token alerts, diagnostic test confirmations, and report download notifications.
  • Explicit Consent & Opt-In: Patients explicitly opt in during sign-up or profile management and can opt out at any time.
  • Privacy Protection: Patient data transmitted via WhatsApp is secured in transit and never shared with third-party advertisers.
